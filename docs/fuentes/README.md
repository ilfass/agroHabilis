# Fuentes centralizadas

Esta carpeta agrupa y organiza todas las fuentes usadas por AgroHabilis para contexto IA.

## Índice
- `fuentes.md` (matriz general de fuentes de datos)
- `fuentes-curadas.md` (fuentes priorizadas por confiabilidad/uso)
- `fuentes-ganaderia.md` (marco y metodología de hacienda)
- `fuentes-magyp-priorizadas.md` (roadmap MAGyP oficial)

## Convención de registro
- Guardar siempre `fuente`, `url`, `fecha de consulta` y `tema`.
- Si una fuente contradice otra, dejar ambas y marcar diferencia.
- Priorizar fuentes oficiales o institucionales para datos críticos.
