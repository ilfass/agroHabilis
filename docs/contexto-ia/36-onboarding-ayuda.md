# Módulo 36 — Onboarding y ayuda

## Propósito
Asistir a usuarios nuevos (o con dudas de uso) para
configurar AgroHabilis y obtener valor rápido.

## Qué debe explicar este módulo
- Qué puede hacer AgroHabilis
- Cómo cargar perfil productivo y zona
- Cómo registrar cultivos/ganadería/costos
- Cómo pedir resúmenes, alertas y análisis

## Flujo sugerido de ayuda
1. Alta de usuario y validación de datos básicos
2. Carga de ubicación y actividad principal
3. Carga de cultivos/stock/costos iniciales
4. Primer consulta guiada y primer resumen

## Errores comunes a resolver
- Usuario sin perfil completo
- Datos incompletos de zona o actividad
- Confusión entre comandos y lenguaje natural

## Cómo responder consultas de ayuda
- Responder en pasos cortos y accionables
- Confirmar avance antes de pasar al siguiente paso
- Evitar términos técnicos innecesarios
